# Contributing to tsudev

Thank you for helping! These defaults apply to every `tsudev-org` repository that does not ship its own
`CONTRIBUTING.md` (several do - check the repository root first).

_Tiếng Việt: mọi đóng góp đều được chào đón - báo lỗi, đề xuất tính năng, dịch, sửa tài liệu hay gửi pull request. Bạn có thể viết issue bằng tiếng Việt hoặc tiếng Anh._

## Ways to help

- **Report a bug** - open an issue with the *Bug report* form: version, OS, steps to reproduce, what you expected.
- **Suggest a feature** - open an issue with the *Feature request* form, or start a Discussion where enabled.
- **Translate** - most apps are Vietnamese-first; English and other languages are very welcome.
- **Spread the word** - a star, a blog post or a review on [AlternativeTo](https://alternativeto.net/) helps a small
  project more than you might think.

## Pull requests

1. Open an issue first for anything larger than a typo, so we can agree on the approach.
2. Keep each pull request to one change; follow the existing code style (formatters and linters run in CI).
3. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages (`fix: ...`, `feat: ...`).
4. CI must be green. New behaviour needs a test where the repository has tests.
5. By contributing you agree your work is licensed under the repository's license.

## Security

Never report vulnerabilities in public issues - use **Report a vulnerability** on the repository's Security tab.
See [SECURITY.md](SECURITY.md).

## Code of conduct

Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md).
