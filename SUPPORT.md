# Getting help

- **Documentation:** <https://tsudev.com/docs> and each project's README.
- **Questions and ideas:** the project's *Discussions* tab where enabled, otherwise an issue.
- **Bugs:** an issue using the *Bug report* form.
- **Security:** never public - see [SECURITY.md](SECURITY.md).

_Tiếng Việt: hỏi đáp và báo lỗi bằng tiếng Việt đều được._
