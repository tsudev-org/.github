# Security policy

Applies to every `tsudev-org` repository that does not ship its own `SECURITY.md`.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private vulnerability reporting: open the affected repository, go to
**Security → Report a vulnerability** (`https://github.com/tsudev-org/<repository>/security/advisories/new`).

Please include the affected component and version, steps to reproduce (a minimal proof of concept is enough) and the
impact you see. You will get a first reply within **7 days**. Once a fix ships, the issue is published as a GitHub
Security Advisory and you are credited if you wish.

_Tiếng Việt: đừng báo lỗ hổng qua Issue công khai - dùng **Security → Report a vulnerability** của repo bị ảnh hưởng. Phản hồi trong 7 ngày._

## Supported versions

Only the latest release of each project receives security fixes. Install and update through a package manager
(winget, Scoop, Homebrew, APT/DNF - see <https://tsudev.com/apps#cai-bang-lenh>) to stay current.
